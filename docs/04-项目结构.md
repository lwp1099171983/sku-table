# 项目结构约定

## 目标

项目采用 pnpm workspaces 管理前端、后端和共享代码。目录边界对应部署边界，避免页面、API、数据库配置和运维脚本混在同一个 `src` 目录。

## 目录职责

| 目录 | 职责 | 依赖方向 |
|---|---|---|
| `apps/web` | React/Vite 页面、布局、前端 services | 依赖 `packages/shared`，通过 HTTP 调用 API |
| `apps/api` | Hono 路由、中间件、认证、业务服务和数据库访问 | 可依赖 `packages/shared`，不被页面代码反向依赖 |
| `packages/shared` | DTO、领域类型和跨端常量 | 不依赖前端、Node 或数据库驱动 |
| `infra/docker` | Docker Compose、服务编排和生产环境变量约定 | 只负责部署，不放业务代码 |
| `infra/nginx` | HTTP/HTTPS 站点模板、80/443 未匹配域名拒绝配置和 `/api` 反向代理 | 只负责入口、证书引用和网络转发 |
| `infra/scripts` | 备份、恢复、健康检查等运维脚本 | 调用部署工具，不被业务代码导入 |
| `infra/systemd` | 数据库备份等宿主机 systemd 单元模板 | 只负责定时任务，不包含凭据 |
| `infra/legacy/supabase` | 历史兼容迁移材料 | 不参与 v1 主流程 |
| `docs` | 需求、技术选型、任务拆分和结构约定 | 不被运行时代码依赖 |

## 新功能放置规则

- 新页面放在 `apps/web/src/pages`，页面通过 `apps/web/src/services` 访问 API。
- 新 API 路由放在 `apps/api/src/routes`，认证和通用错误处理放在 `middleware`；路由共享工具（`readBody`、店铺范围/删除范围解析）在 `apps/api/src/routes/helpers.ts`。
- 台账领域规则放在 `apps/api/src/modules/ledger`：`calculation.ts` 负责重量与利润重算，`shippingRateParser.ts` 解析物流资费 Excel，`shippingRateRepository.ts` 负责资费版本与规则读写，`dedupe.ts` 负责文件内订单号去重，`repository.ts` 负责台账持久化与批次行数。
- 物流资费管理页为 `apps/web/src/pages/ShippingRatesPage.tsx`，通过 `apps/web/src/services/shippingRatesService.ts` 调用仅管理员可用的 `/admin/shipping-rates` API。
- 数据库 schema、迁移和 repository 只放在 `apps/api`，禁止从前端导入；RBAC 目录数据迁移位于 `apps/api/src/db/migrations/0006_rbac_catalog.sql` 及后续增量迁移（当前至 `0013_ledger_soft_delete.sql`），不得仅依赖可选 seed。
- Excel 导入共享工具（行数/大小上限、表头与文本标准化）在 `apps/api/src/modules/imports`；bcrypt 轮数等常量在 `apps/api/src/modules/auth/constants.ts`。
- 固定汇率配置在 `apps/api/src/config/exchangeRate.ts`；更新汇率时需同步更新尾程历史回算迁移或另建增量回算迁移。
- 前后端都需要的请求/响应类型放在 `packages/shared/src`。
- Docker、Nginx、备份和恢复脚本放在 `infra`，不要放进应用源码目录。

## 本地启动

在仓库根目录执行 `pnpm install` 后，分别运行 `pnpm dev:web` 和 `pnpm dev:api`。前端默认请求 `http://localhost:3000/api`，可在 `apps/web/.env` 覆盖。

## 账号管理模块

- 路由：`apps/api/src/routes/adminUsers.ts`（挂载于 `/admin/users`，权限码 `user.manage`，仅管理员），`/auth/change-password` 位于 `apps/api/src/routes/auth.ts`。
- 页面：`apps/web/src/pages/AdminUsersPage.tsx`（账号列表、重置密码、停用/启用），改密入口在 `apps/web/src/layouts/AppLayout.tsx` 顶部用户菜单。
- 服务：`apps/web/src/services/adminUsersService.ts`；共享 DTO 见 `packages/shared/src/dto.ts`（`AdminUserDto` 等）。
