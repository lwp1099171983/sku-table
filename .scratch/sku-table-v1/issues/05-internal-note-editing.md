# 05 — 内部备注编辑

**What to build:** 任意已登录团队成员可以在线编辑商品内部备注并保存；多人同时编辑同一条备注时采用最后写入覆盖，且编辑备注不会改变其他商品字段。

**Blocked by:** 01 — 服务器、PostgreSQL 与安全基线；02 — Node.js API 与受保护登录态；04 — 商品列表与上传人筛选

**Status:** ready-for-agent

- [ ] 内部备注支持编辑、保存和失败提示，保存后刷新内容仍然存在
- [ ] 任意已登录团队成员都可以编辑内部备注，不受商品上传人限制
- [ ] 更新只允许修改内部备注和系统更新时间，不能修改商品归属、批次或原始导入字段
- [ ] 两个成员先后保存同一条备注时，最终内容以最后一次成功写入为准
- [ ] 网络或权限错误时显示保存失败，并以服务端数据恢复展示
- [ ] v1 不记录备注修改人、修改历史、旧值和新值
