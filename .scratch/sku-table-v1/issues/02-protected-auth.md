# 02 — Node.js API 与受保护登录态

**What to build:** 提供 Node.js API、邮箱密码登录、JWT 登录态和团队成员权限，让前端通过 API 访问业务数据，未登录或未开通账号无法读取数据。

**Blocked by:** 01 — 服务器、PostgreSQL 与安全基线

**Status:** ready-for-agent

- [ ] API 提供健康检查和登录接口，已开通成员可以登录并获得有效登录令牌
- [ ] 密码使用安全哈希保存，接口不返回密码哈希，登录失败不泄露账号是否存在
- [ ] 未登录访问商品页和导入页时自动跳转到登录页
- [ ] 未开通账号不能进入业务数据页面
- [ ] API 从 JWT 确定当前用户，客户端伪造 `created_by`、角色或用户 ID 不会改变服务端身份
- [ ] `owner` 和 `selector` 可以导入，`operator` 只能查看商品和编辑内部备注
- [ ] 前端页面通过统一业务服务访问 API，不直接依赖数据库驱动
