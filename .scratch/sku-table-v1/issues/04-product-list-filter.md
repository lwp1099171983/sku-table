# 04 — 商品列表与上传人筛选

**What to build:** 登录成员可以分页浏览团队商品，并按上传人筛选，列表展示商品核心字段和导入追溯信息，适用于几十万行数据规模。

**Blocked by:** 01 — Hono.js/Node.js 后端与数据库基础；02 — 认证、权限与 Hono API

**Status:** ready-for-agent

- [ ] 商品列表使用服务端分页，每页 100 条，翻页不重复、不遗漏
- [ ] 可以按已开通成员筛选上传人，结果与商品归属一致
- [ ] 列表展示货号、商品名称、平台、价格、规格、链接、上传人、上传时间和内部备注
- [ ] 50 万行数据下分页和上传人筛选使用索引，真实环境 p95 响应时间小于 1 秒
- [ ] 未登录或未开通账号不能通过列表请求读取业务数据
