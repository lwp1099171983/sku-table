# 03 — Excel 导入与失败恢复

**What to build:** 选品员可以通过 Hono.js API 导入固定模板的 Excel 文件，查看逐步进度和批次结果；Node.js 服务端负责解析和分块写入，导入失败可以定位并重试，重试不会重复写入已成功的数据。v1 不提供整批回滚，批次回滚属于 v1.1。

**Blocked by:** 01 — Hono.js/Node.js 后端与数据库基础；02 — 认证、权限与 Hono API

**Status:** ready-for-agent

- [ ] 支持 `.xlsx` 和 `.xls`，并对表头、空文件、商品名称、价格格式和 5 万行上限进行校验
- [ ] 导入页面展示待处理行数、成功写入数、总行数和当前状态
- [ ] 每次导入生成批次记录，包含文件名、上传人、时间、状态、总数、成功数和失败数
- [ ] 每行数据自动关联当前成员、创建时间和批次 ID，前端不能覆盖系统字段
- [ ] 部分失败时展示失败范围和原因，支持从失败位置重试且不会产生重复数据
- [ ] 真实腾讯云服务器环境下 5 万行导入在 2 分钟内完成，页面结果与批次结果一致
- [ ] 导入接口测试覆盖文件类型、行数上限、权限不足、部分失败和重复重试场景
