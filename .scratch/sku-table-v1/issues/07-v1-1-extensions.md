# 07 — v1.1 扩展功能

**What to build:** 在 v1 稳定运行后，增加管理员和成员管理、商品查找、授权数据维护及批次回滚能力，同时保持 v1 的导入追溯和备注编辑行为不变。

**Blocked by:** 03 — Excel 导入与失败恢复；04 — 商品列表与上传人筛选；05 — 内部备注编辑

**Status:** ready-for-agent

- [ ] 管理员可以管理团队成员和角色，非管理员不能执行成员管理操作
- [ ] 支持按平台筛选，以及按货号或商品名称模糊搜索
- [ ] 上传人可以删除自己导入的商品，管理员可以按授权规则删除任意商品
- [ ] 授权用户可以编辑货号、价格等商品字段，但系统字段仍受保护
- [ ] 批次管理页可以查看导入历史，并执行可确认、可恢复的整批回滚
- [ ] v1.1 不包含操作审计、修改历史和删除日志
